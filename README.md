# 禧悦妆造 · 绢本妆册

化妆师甜茉的跟妆作品集（H5 优先）。设计方向：**Luxury / refined × 新中式编辑排版** ——
宣纸米白为底、墨色为文、朱砂印章为魂，竖排书法标题 + 册页式相册 + 团扇形特写。

## 本地预览

```bash
python3 -m http.server 8787
# 打开 http://localhost:8787
```

（直接双击 index.html 也能跑，但建议走 http 以获得正确字体与懒加载行为）

## 目录结构

```
muaPortfolio/
├── index.html            # 入口（含查看器 / 墨晕过渡层）
├── styles/
│   ├── tokens.css        # 设计令牌：颜色 / 字阶 / 间距 / 阴影 / 动效
│   ├── base.css          # 重置 / 纸纹氛围 / 页面转场 / 降级动效
│   └── components.css    # 印章 / 册页 / 签牌 / 团扇 / 查看器
├── scripts/main.js       # hash 路由 + 交互（零构建，原生 JS）
├── data/albums.js        # 站点数据（纯前端版，后期可换 API）
└── assets/img/           # ★ 全部为 AI 占位图，按同名文件替换真实客片
```

## 内容口径（已与需求方核对）

- 壹 · 婚庆跟妆：**每场婚礼一册**；册内**新中式 / 西式严格隔离**；
  二级按婚礼当天流程：晨袍 → 出门 → 仪式（主纱）→ 迎宾 → 敬酒；
  每册带「细节 · 特写」（头饰造型 / 面部细节，团扇展示）
- 贰 · 订婚宴跟妆：平铺图集　|　叁 · 孕妇照 · 亲子照跟妆：平铺图集
- **只呈现作品**：不展示客户姓名 / 婚期 / 价格

## 替换真实客片（上线前必做）

1. `assets/img/` 下的 `hero / nc-a / nc-b / nc-c / w-a / w-b / closeup-head / closeup-face / portrait / family`
   按同名替换（展示图建议长边 1600px、WebP、≈200KB；上传时生成，原图仅查看器加载）
2. 新增一场婚礼：在 `data/albums.js` 的 `weddings` 里加一条（编号序号顺延）
3. 替换「关于我」页的微信二维码（`qr-card` 占位框）
4. 字体：当前走 Google Fonts，国内上线建议自托管或换 `fonts.loli.net` 镜像
