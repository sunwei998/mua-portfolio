Engineering Notes

玻璃分层配方 · 降级矩阵 · 性能预算 · 比例规范

层实现参数
① 高光.glass::before 双层背景：斜向静态光泽 + 跟随指针/陀螺仪的径向光斑，mix-blend-mode:screenradial 240×200 at var(--mx) var(--my) · 线性 118deg
② 折射可选 .lens 层：filter:url(#lgRefract) blur(7px)（feTurbulence + feDisplacementMap）仅固定层，每帧 4–8ms；滚动区禁用
③ 模糊backdrop-filter: blur() saturate() brightness()（必须带 -webkit- 前缀）真玻璃 22–28px / 轻玻璃 11–14px；saturate 150–180%
④ 底色--gt 线性渐变 + .scrim 暖色底（解决白婚纱糊字）白 8–30% 透明；scrim rgba(255,246,240,.10)
⑤ 色散边.glass::after 三向 inset 描边（暖粉 / 冷蓝 / 白底边）inset 1px 0 0 粉 · inset -1px 0 0 蓝
⑥ 投影外阴影 0 16px 40px rgba(30,22,18,.13)环境色取墨色而非纯黑
运行环境backdrop-filter真折射 url()落地档位
Android 微信（X5）✕ 静默忽略✕假玻璃：半透明 + 内高光 + 1px 白描边，零 GPU，视觉接近不掉帧
iOS 微信（WKWebView）✓ 跟随 Safari✓ 16.4+真玻璃
Safari 15.4+✓（需前缀）✓ 16.4+真玻璃
Chrome / Edge 76+✓✓真玻璃
Firefox 103+✓✓真玻璃
红线说明
禁 overflow + radius玻璃元素本身同时写 overflow:hidden 与 border-radius → Safari 直接放弃模糊；裁切一律交给 ::before 的 border-radius:inherit
禁 will-change 叠加will-change:transform / translateZ(0) 与 backdrop-filter 叠加会炸层，掉帧
@supports 不可信旧 WebKit 会对 @supports (backdrop-filter) 返回 true 但不生效 → 需配 UA / 特性实测判断
白纱 scrim玻璃层上文字一律墨色，统一压 8–12% 暖色 scrim；禁用纯白字
数量上限同屏真玻璃 ≤ 3 处；滚动容器内只用轻玻璃（11–14px）
构图占比（预估）处理规则
3:4 竖约 55%主栅格，单列全幅、双联各占一半
2:3 竖约 25%同 3:4 容器，object-fit:cover，容器高度按 aspect-ratio 自适应
4:5 竖约 12%同上，略矮；双联时与 3:4 混排不强制等高
3:2 / 4:3 横约 6%不裁人物：单独占一整行，按原比例展示，高度 = 宽度 ÷ 比例
16:9 横约 2%同上；若确为全景，允许上下留白（letterbox）
